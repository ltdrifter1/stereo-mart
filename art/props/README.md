# Stereo-Mart hotspot props

Transparent PNG sprites cut from the Y2K equirect rebuild. Use these as
krpano / R3F billboards, animated toys, or panel thumbs — separate from the
baked environment plate.

| File | Hotspot / use |
|---|---|
| `crt.png` | Videos — silver CRT (dark empty tube) |
| `register.png` | Shop — cream cash register |
| `phone.png` | Contact — black rotary phone |
| `listen.png` | Music — headphones + turntable shelf |
| `bins.png` | Artists — vinyl island |
| `crates.png` | Floor milk crates |
| `sign.png` | Storefront STEREO-MART lettering |
| `album.png` | Generic sleeve art |

Runtime copies also ship under `public/hotspots/props/`.
